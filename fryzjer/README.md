# Demo strony dla salonu fryzjerskiego

Folder `fryzjer/` zawiera gotową statyczną stronę demo dla salonu fryzjerskiego / beauty.

## Co jest w środku

- nowoczesny hero z CTA do rezerwacji,
- sekcja usług,
- galeria/metamorfozy,
- proces wizyty krok po kroku,
- cennik,
- zespół,
- opinie klientek,
- formularz rezerwacji demo,
- responsywne menu mobilne.

## Plik startowy

Otwórz lokalnie:

```txt
fryzjer/index.html
```

## Do podmiany pod realnego klienta

- nazwa salonu,
- numer telefonu,
- adres,
- cennik,
- zdjęcia realizacji,
- link do Booksy / Calendly / formularza e-mail.

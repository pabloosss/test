# Strony demo

Folder zawiera przykładowe strony branżowe używane na stronie promującej usługę tworzenia stron internetowych.

## Dostępne dema

- `demo/kebab/` — kebab / restauracja
- `demo/kwiaciarnia/` — kwiaciarnia z dostawą
- `demo/warsztat/` — mechanik / warsztat
- `demo/beauty/` — beauty / barber

Dane kontaktowe i treści można później podmienić pod prawdziwych klientów.
